Próxima capa de datos

Para cada maternidad, el monitor queda preparado conceptualmente para incorporar:

  • disponibilidad de anestesiólogo/a para obstetricia por turno;
  • posibilidad efectiva de analgesia peridural 24/7;
  • cantidad de partos vaginales y cesáreas;
  • dotación/cargos cubiertos y vacantes;
  • fecha de incorporación al cronograma oficial;
  • observaciones y fuente de verificación.

Hasta contar con una fuente homogénea, CEPOES no asignará semáforos de cumplimiento por hospital.
